# Fundamentos de Shell Script

Esta seção reúne exercícios e laboratórios relacionados aos fundamentos de Shell Script e Bash.

- Shebang (`#!/bin/bash`)
- `echo` e `read`
- Variáveis
- Operações matemáticas
- Comparadores
- Estruturas condicionais
- Operadores lógicos
- Laços `for` e `while`

> Conteúdo em evolução conforme o avanço dos estudos.
